2// Logging for TinyBLEFS with log levels and a configurable output.
3//
4// TinyBLEFSLogger.begin(Serial, LogLevel::Debug); // Arduino
5// TinyBLEFSLogger.setLevel(LogLevel::Warning); // change level
6// TinyBLEFSLogger.setOutput(otherPrint); // change output
7//
8// On Arduino boards nothing is printed until an output is defined. On
9// desktop systems the default output is stderr.
10//
11// Library code logs with TINYBLEFS_LOGE / LOGW / LOGI / LOGD(tag, fmt, ...); the
12// arguments are only evaluated when the level is enabled. Applications can
13// log with the same macros or with TinyBLEFSLogger.log(...).
