Detailed Description

Serves a file system (any FsBackend, given in the constructor) over a Transport.

Call poll() regularly from loop().

ArduinoFsBackend<fs::LittleFSFS> backend(LittleFS); FileServer server(backend, transport, "sensor1"); // one client FileServer server(backend, transport, "sensor1", "/", 3); // up to 3 clients void loop() { server.poll(); }

Every client works in its own session (own open files); the clients share the file system and its locks. maxSessions limits the clients at the same time (a further client is refused); with 1 the server serves one client at a time.
