Detailed Description

Peripheral side: advertises the TinyBLEFS service via BlueZ (GATT server) and talks to one client.

SimpleBLE can't set the BLE device name: BlueZ advertises the alias of the adapter. Set it with bluetoothctl system-alias "TinyFS PC" (this is the name the client scan prefix is compared with).
