◆ keepAlive()

void tinyblefs::FileClient::keepAlive ( )
inline

Keeps the session alive while the application is idle: the server closes sessions without packets for 60 s (and with them the open files).

Call it at least once in that time. If the session was closed, the next request fails and the one after joins again (files that were open are lost).
